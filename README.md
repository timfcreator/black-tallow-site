# Black Tallow website

The website for Black Tallow, built with [Eleventy](https://www.11ty.dev/) and published on GitHub Pages.

## Run it on your machine

You need Node.js 24 (LTS). In this folder:

```
npm install
npm start
```

`npm start` serves the site at http://localhost:8080 and reloads the page whenever a file changes.
`npm run build` writes the finished site to `_site/`.
